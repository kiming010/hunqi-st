# 魂器 ST 插件（本地模拟版 v0.2）

只解决一个问题：**存得进去，倒得回去。**

- **存档**：把现在这个 TA 的角色卡和**全部聊天原件**存进魂器
- **整理摘要**：用你现在连着的模型，把当前这段聊天整理成摘要
- **唤醒**：把 TA 放回这家酒馆，直接打开上次聊的那段

## 两种存法

| | 魂器文件夹 | 存档文件 |
|---|---|---|
| 什么时候用 | 电脑上的 Chrome / Edge，ST 是 `https://` 或 `localhost` 打开的 | 其他情况：`http://192.168.x.x` 局域网地址、Firefox、iPhone、手机浏览器 |
| 存档 | 点**存档**，直接写进文件夹（可以是魂器 U 盘） | 点**下载存档文件**，得到一个 `.hunqi.zip`，自己放到 U 盘或网盘 |
| 唤醒 | 下拉框选 TA，点**唤醒** | 点**从文件唤醒**，选那个 `.hunqi.zip` |
| 摘要存在哪 | 魂器文件夹里 | 浏览器里，下载存档文件时一起打进包 |

存档文件就是把魂器文件夹整个打成 zip，里面的结构一模一样：解压到 U 盘上就是一个魂器，用系统自带的解压工具也能打开看。
面板会自己判断用哪种；能读写文件夹时，两种按钮都在。

硬件不是必须的。魂器硬件的 U 盘模式本身就是一个文件夹。

## 装上

### 用"安装扩展程序"（云酒馆、局域网里的 ST 都用这个）

1. 打开扩展面板（顶栏三个方块的图标），点右上角的**安装扩展程序**（注意不是中间的"资源网址"框）
2. 在弹出的窗口里粘贴 `https://github.com/kiming010/hunqi-st`，安装
3. 刷新页面，扩展面板右边那一列能看到"魂器（本地模拟）"
4. 以后更新：**管理扩展程序** → 找到它点更新 → 刷新页面

局域网 http 地址也想用魂器文件夹：在 Chrome 打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，填上你的 ST 地址（比如 `http://192.168.1.10:8000`），改成 Enabled，重启 Chrome。

### 本地 ST

1. 把整个 `hunqi-st` 文件夹复制到 ST 的扩展目录，二选一：
   - 只给自己用：`SillyTavern/data/default-user/extensions/hunqi-st`（多用户时把 `default-user` 换成你的用户名）
   - 给所有用户用：`SillyTavern/public/scripts/extensions/third-party/hunqi-st`
2. 刷新 ST 页面
3. 打开扩展面板（顶栏三个方块的图标），能看到"魂器（本地模拟）"

## 试一遍（用一个测试角色，别拿真的 TA 试删除）

1. 新建一个空文件夹，比如"魂器模拟"。在面板里点**选择魂器文件夹**，选它
2. 打开一个测试角色（比如 ST 自带的 Seraphina），聊几句，点**存档**
3. 去文件夹里看：`souls/<一串 ID>/` 下有 `card.png`、`chats/`、`soul.json`。聊天文件可以直接用文本编辑器打开
4. 点**整理摘要**，会弹出摘要。摘要存在 `summary/` 里
5. 在 ST 里把这个测试角色删掉（连聊天一起删）
6. 在面板下拉框里选它，点**唤醒**。检查：卡回来了，聊天条数对得上，打开的是上次聊的那段
7. 想看摘要有没有跟着回来：打开 ST 自带的"总结（Summarize）"扩展，里面应该显示刚才的摘要

用存档文件试：第 1 步跳过；第 2 步点**下载存档文件**；第 6 步点**从文件唤醒**，选下载的 `.hunqi.zip`。

## 规矩

- 聊天原件一个字节不改，内容没变就不重写
- 酒馆里删了消息、聊天变短了：魂器先把旧版本留进 `chats/_old/`，再存新的
- 酒馆里整段聊天删掉了：魂器里的原样留着，永远不删
- 唤醒时只在魂器里的聊天**更完整**时才写回去，不会把酒馆里的聊天改短
- 摘要是从原话算出来的，永远不覆盖原话。倒回 ST 时放在 ST 自带摘要扩展认的位置（倒数第二条消息的 `extra.memory`）；聊天里已经有 ST 自己的摘要就不动它
- 魂器给每个 TA 发一个固定的 ID，写在角色卡的 `data.extensions.hunqi.soul_id` 里。因为 ST 自己没有稳定的角色 ID

## 这一版不做

世界书、预设、正则、立绘、群聊、加密。

## 魂器文件夹长这样

```
hunqi.json                      这是一个魂器
souls/<soul_id>/soul.json       这个 TA 的清单：名字、每段聊天几条、指纹、上次在聊哪段
souls/<soul_id>/card.png        角色卡（ST 导出的 PNG）
souls/<soul_id>/chats/*.jsonl   聊天原件
souls/<soul_id>/chats/_old/     酒馆里聊天变短时留下的旧版本
souls/<soul_id>/summary/*.json  摘要，以及整理到了第几条
```

## 开发

- `lib.js`：魂器容器的逻辑，不碰 ST，只碰文件夹
- `index.js`：ST 里的面板和按钮，也就是"插头"
- 本地测试：`npm test`（用真文件夹模拟魂器，跑存档、读取、摘要放置的逻辑；ST 那一侧要装进 ST 里实测）
- ST 接口对照的是官方源码 release 分支 v1.19.0
